# Jeremy White — CS-499 Computer Science Capstone ePortfolio

Live site: **https://jeremywhite4.github.io/**

CS-499 Computer Science Capstone. It presents three artifacts enhanced across the core areas
of computer science, each with its original code, enhanced code, and a reflective narrative.
